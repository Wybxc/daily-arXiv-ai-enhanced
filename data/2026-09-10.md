### [1] [UnsafeChecker: Finding Soundness Bugs in Rust Safe Abstractions](https://arxiv.org/abs/2609.09641)
*Xizhe Yin,Yaokun Zhang,Yang Feng,Baowen Xu*

Main category: cs.PL

TL;DR: 本文提出 UnsafeChecker，一个编译器集成的 Rust 静态分析框架，基于 MIR 的流敏感抽象解释，通过所有权、对象有效性和布局三元共享状态检测安全抽象中的潜在健全性（soundness）违规。

Motivation: Rust 通过所有权与借用系统在无 GC 前提下保证内存安全，但底层系统编程中大量库依赖 unsafe 关键字，将裸指针操作封装为安全 API。内部 unsafe 代码的单一错误会破坏安全契约，导致抽象不健全，使安全客户端触发未定义行为。现有 C/C++ 静态分析工具忽略 Rust 特有的安全契约，而当前 Rust 工具缺乏追踪裸指针所擦除上下文的深层语义建模能力。

Method: UnsafeChecker 分析 Rust MIR，采用流敏感抽象解释，维护包含所有权、对象有效性、布局三部分的共享状态；每条告警规则按对应的 Rust 安全义务消费所需事实子集，同时报告指令级未定义行为与可能经安全 API 逃逸的边界级契约违规。

Result: 在 46 个 RustSec 漏洞（含 53 个真实缺陷）基准上，检测出 32 个 CVE，覆盖 36 个缺陷（召回率 67.9%），告警级精确率 51.6%，优于多个先进工具。在 crates.io 真实 crate 大规模扫描中，发现 83 个 crate 中 114 个未知缺陷，其中 45 个已确认、27 个已被维护者修复。

Conclusion: UnsafeChecker 通过编译器集成的流敏感抽象解释与多维共享状态建模，有效弥补了现有工具在 Rust 安全抽象健全性检测上的不足，实验证明其检测能力优于现有工具，并具备在真实生态中发现未知缺陷的实用价值。

Abstract: Rust guarantees memory safety without garbage collection through a strict ownership and borrowing system. However, for low-level systems programming, many widely used libraries rely on the unsafe keyword. These libraries encapsulate raw-pointer operations behind safe APIs to form safe abstractions. A single mistake in this internal unsafe code can break its safety contract, rendering the abstraction unsound and allowing safe clients to trigger undefined behavior. Detecting these potential soundness violations is challenging. Existing static analysis tools for C/C++ ignore Rust-specific safety contracts, while current Rust tools lack the deep semantic modeling required to track the contexts that raw pointers erase.
  To address this gap, we present UnsafeChecker, a compiler-integrated static analysis framework for detecting potential soundness violations in Rust safe abstractions. UnsafeChecker analyzes Rust MIR using a flow-sensitive abstract interpretation that maintains a shared state with three components: ownership, object validity, and layout. Each warning rule consumes the subset of facts needed for the corresponding Rust safety obligation. UnsafeChecker reports both instruction-level undefined behavior and boundary-level contract violations that may escape through safe APIs. We evaluate UnsafeChecker on a benchmark of 46 RustSec vulnerabilities, which contain 53 ground-truth bugs. UnsafeChecker outperforms several state-of-the-art tools, detecting 32 CVEs and covering 36 bugs (67.9% recall) with 51.6% alert-level precision. Furthermore, in a large-scale scan of real-world crates on crates.io, UnsafeChecker uncovered 114 previously unknown bugs across 83 crates, with 45 confirmed and 27 already fixed by maintainers.
