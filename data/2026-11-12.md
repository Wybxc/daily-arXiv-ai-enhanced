### [1] [Two-Sided Amortized Resource Analysis: Verifying Resource Lower Bounds via Ill-Typing](https://arxiv.org/abs/2611.12925)
*Zimu Chen,Di Wang*

Main category: cs.PL

TL;DR: 提出一种"两侧类型系统"来验证函数式程序的资源下界，将AARA风格的potential与Ramsay-Walpole两侧类型系统结合，统一在一个证明系统中同时获得上界与下界的可靠性。


<details>
  <summary>Details</summary>
Motivation: AARA只能验证资源上界（typing证明资源充足）；而下界是必要性陈述（只有资源足够程序才能求值），此前基于类型的方法需切换potential的子结构纪律，导致上界与下界分属两套类型系统。作者希望在同一系统中同时刻画上界与下界，从而通过匹配的上下界精确刻画程序开销。

Method: 1) 将AARA式potential与Ramsay–Walpole两侧类型系统结合，核心保证是ill-typed程序不求值；2) 类型公式可约束任意项且出现在turnstile两侧，判断 t : A ⊢ q 表示若t求值得到类型A的结果，则至少需要q单位资源，即q为下界；3) 由于potential使类型公式不可复制，系统采用affine（仿射）纪律而非原框架的可复制上下文；4) 在value state（值与其剩余资源的配对）上做语义类型解释，并在安全片段上证明soundness。

Result: 由soundness可得若干推论：恢复经典两侧类型系统的保证，并在单一证明系统中同时获得两类界的可靠性。OCaml原型类型检查器在19个基准上验证了能精确刻画开销的匹配上下界对，以及为上界不可得的程序验证下界。

Conclusion: 该两侧类型系统统一了资源上下界的验证，是可行且实用的；另有并行探索：全值皆为不可复制资源的两侧线性类型系统中，捕获线性资源的闭包需要双重的类型公式，其精确记账解释了主系统为何采用affine设计。

Abstract: We present a two-sided type system with potential for verifying resource lower bounds of functional programs. Automatic amortized resource analysis (AARA) verifies upper bounds: types carry potential, and typing certifies sufficient resources. A lower bound, however, is a necessity statement---the program evaluates only if enough resources are available---and prior type-based approaches obtain it by switching the substructural discipline of potential, so that upper and lower bounds live in separate type systems. Matching upper and lower bounds characterize a program's cost exactly.
  Our system combines AARA-style potential with the two-sided type systems of Ramsay and Walpole, whose central guarantee is that ill-typed programs do not evaluate. Typing formulas may constrain arbitrary terms and appear on both sides of the turnstile; the judgment $t : A \vdash q$ states that if $t$ evaluates to a result of type $A$, then at least $q$ units of resource must be available---that is, $q$ is a lower bound. Because potential makes typing formulas non-replicable, our system follows an affine discipline instead of the replicable contexts of the original framework. We interpret types by semantic typing over value states, pairs of values and remaining resources, and we prove soundness on a safety fragment; corollaries recover the classical two-sided guarantees and the soundness of both kinds of bounds in a single proof system. A prototype type checker in OCaml verifies, on a suite of 19 benchmarks, matching pairs of bounds that characterize costs exactly, as well as lower bounds for programs whose upper bounds are unavailable. In a parallel exploration, we study a two-sided linear type system in which every value is a non-replicable resource; there, closures that capture linear resources call for dual typing formulas, and the exact accounting explains the affine design of the main system.

Abstract: Modern accelerators specialize recurring computation and replicate it across regular hardware structures to achieve high performance. Sustaining this parallelism requires equally deliberate data delivery. Yet design tools often express these structures as sequential programs or flatten them into separate hardware modules and connections. This obscures shared patterns and leads to repeated compiler work. We introduce Single Program, Multiple Connected Work Units (SPMW), a grid-based programming model for scalable accelerator design that makes grid regularity a first-class abstraction. SPMW decouples local work-unit behavior from grid connectivity and data delivery. To our knowledge, SPMW is the first programming model to retain regularity throughout the compilation process, combining behavioral HLS with structural RTL generation for both fixed-function and domain-specific instruction-programmable accelerators. Our FFT achieves up to 2.65x lower latency than HP-FFT. Our mini-TPU and our SPMW implementation of the FEATHER accelerator demonstrate complex composition and outperform their RTL baselines. Parallel functional simulation provides up to 18.4x speedup over Vitis HLS C simulation on the mini-TPU workloads. SPMW is also agent-friendly: given the same design specification, all five coding agents produce SPMW designs that satisfy the correctness and latency requirements, with 7.51x lower token usage than for SystemVerilog.

### [4] [Context Types: Bunched Modalities for Unifying Safety and Reachability](https://arxiv.org/abs/2611.13471)

<details>
  <summary>Details</summary>
Motivation: 传统类型系统主要验证安全性质（判断 e:τ 表示 e 可能求值到的值都落在 τ 的指称中），而另一类可达性/活性性质（e 必须能够求值到 τ 指称中的每个值）通常需独立设计。二者对上下文变量绑定的解释施加不同约束，难以共存于同一系统中，本文旨在消除这一割裂。

Method: 1) 面向高阶函数式程序设计精化类型系统，使类型可同时表达安全与可达性；2) 将类型上下文视为资源，用以刻画在类型推导时可用的“能力”；3) 定义上下文能力的资源代数，并在其上构建束式模态上下文逻辑（bunched modal context logic）；4) 将类型系统在该逻辑中解释，从而混合推理两类性质。

Result: 给出一个统一的指称语义模型，使安全与可达性在同一类型判断内得到刻画；并证明该精化类型系统相对于此指称语义是可靠的（soundness）。

Conclusion: 通过资源化的上下文解释与束式模态逻辑，安全性质与可达性性质可以同时纳入一个类型判断并以同一逻辑框架加以论证，为统一验证“可能成立”与“必然可达”提供可行基础。

Abstract: Most type systems are designed to verify safety properties: the judgement $e : τ$ holds if $e$ may evaluate to any value contained in the denotation of $τ$, but nothing more. More recent type systems have considered the complementary class of reachability properties: in these systems, the typing judgment holds if $e$ must be able to evaluate to every value denoted by $τ$, and possibly more. This paper introduces a refinement type system for higher-order functional programs where types can capture both safety and reachability properties. Simultaneously supporting both is challenging because each imposes different constraints on how variable bindings in a typing context are interpreted. We address this challenge by treating typing contexts as a kind of resource that mediates which capabilities are available when typing a program. We formalize this notion by developing a resource algebra of contextual capabilities and a bunched modal context logic over this algebra. We then interpret our type system in this logic, establishing soundness with respect to a denotational semantics that unifies safety and reachability guarantees within a single typing judgement.
