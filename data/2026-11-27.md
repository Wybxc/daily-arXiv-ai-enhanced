### [1] [SeQLean: Verifying SQL queries using Lean](https://arxiv.org/abs/2611.33181)
*Siddhartha Gadgil,Anirudh Gupta,Ajay Kumar Nair*

Main category: cs.PL

TL;DR: SeQLean 利用 Lean 形式化验证（通过关系代数对 SQL 建模）提升自然语言到 SQL 翻译的准确性，借助"证明挑战"（内部一致性测试）检测错误翻译，并提供 HTTP JSON API 集成到智能体框架中。


<details>
  <summary>Details</summary>
Motivation: 自然语言到 SQL 的翻译缺乏已知正确的参照，无法直接证明正确性，因此需要一个能间接检验翻译可靠性的机制。

Method: 用关系代数在 Lean 中形式化 SQL；采用"证明挑战"进行内部一致性检验。最简单的挑战是对同一自然语言查询生成两个 SQL 翻译（一个偏性能、一个偏可读性），若二者等价则对任意数据库结果相同，可用 Lean 自动化证明检查；并能纳入底层数据库系统的已知性质。

Result: 可表达近乎任意的证明挑战属性并检验（含等价性），且考虑数据库系统性质；在算术类等价查询上，借助 Mathlib 定理，Lean 比传统工具有更强能力。提供基于 HTTP 的 JSON API，可将验证器集成到智能体框架。

Conclusion: SeQLean 通过 Lean 形式化验证与证明挑战机制，在不具备正确翻译真值的前提下有效提升 NL2SQL 翻译可信度，并具备良好的工程可集成性。

Abstract: We present SeQLean, a system that uses formal verification in Lean to increase the accuracy of translation from natural language to SQL. This is based on modelling SQL in Lean via relational algebras. Since we do not have a translation known to be correct, we cannot directly prove correctness. Instead, we use proof challenges: tests of internal consistency that are unlikely to be satisfied by an incorrect translation. The simplest proof challenge is based on generating two translations of the same natural language query into SQL, ideally with one being optimized for performance and the other for understandability. If two translations are equivalent, they must give the same answer for every database. This can be checked using proof automation in Lean. Using Lean allows us to have essentially arbitrary properties as proof challenges, and also check these (including equivalence) taking into account known properties of the underlying database system. Even for equivalence queries of an arithmetic nature, we show that Lean can be more powerful than traditional tools due to the availability of Mathlib theorems. A JSON API over HTTP allows the verifier to be integrated into agentic frameworks.

### [2] [SentryWard: Formal Verification of Warp-Specialized GPU Kernels](https://arxiv.org/abs/2611.33817)
*Mengdi Wu,Sreeram Vennam,Stephen Mell,Ziwei Zhou,Advay Kadam,Xinhao Cheng,Francois Costa,Alex Aiken,Oded Padon,Zhihao Jia*

Main category: cs.PL

TL;DR: SentryWard 是一个面向 warp-specialized GPU kernel 的形式化验证框架，通过"良同步"分析构造与调度无关的 happens-before 图，统一完成同步验证、数据竞争与资源生命周期分析和功能等价性检查。


<details>
  <summary>Details</summary>
Motivation: 现代 GPU kernel 采用 warp specialization 重叠异步数据搬运、通用核（CUDA core）计算与专用核（tensor core）计算，引入了复杂的同步约束；异步操作顺序错误会导致数据竞争、资源过早复用与错误结果。这类错误具有非确定性、可能仅在罕见调度中出现，测试无法保证正确性；而现有 GPU 形式化验证方法对 warp-specialized kernel 支持有限。

Method: 核心思想是证明同步在所有可能执行调度下施加了相同的顺序约束。SentryWard 将良同步分析（well-synchronization analysis）扩展到支持异步事务跟踪的现代 GPU barrier，推导出与调度无关的 happens-before 图，并基于该图验证内存安全、构造输出的符号表达式以进行功能等价性检查。为提升可扩展性，它采用跨线程与张量计算的重复结构紧凑表示；一般假设张量形状和 kernel 启动配置已知，并展开循环。

Result: 框架集成了同步验证、数据竞争与资源生命周期分析以及功能等价性检查三部分能力，并已公开提供实现（https://github.com/gpu-verifier/sentryward）。摘要未给出具体实验数据。

Conclusion: SentryWard 为 warp-specialized GPU kernel 提供了统一的形式化验证方案，以调度无关的 happens-before 图为核心统一支撑内存安全与功能正确性验证，并开源可用。

Abstract: Modern GPU kernels overlap asynchronous data movement, computation on general-purpose cores (e.g., CUDA cores), and computation on specialized cores (e.g., tensor cores) using warp specialization. These asynchronous-overlap optimizations introduce complex synchronization requirements, where incorrect ordering of asynchronous operations can lead to data races, premature resource reuse, and incorrect results. Testing alone cannot guarantee correctness because such errors are nondeterministic and may only manifest in rare execution schedules, and existing GPU formal verification techniques have limited support for warp-specialized kernels.
  We present SentryWard, a framework for formally verifying warp-specialized GPU kernels. SentryWard integrates synchronization verification, data-race and resource-lifetime analysis, and functional equivalence checking. The key idea is to establish that synchronization induces the same ordering constraints across all possible execution schedules. SentryWard extends this well-synchronization analysis to modern GPU barriers with asynchronous transaction tracking and derives a schedule-independent happens-before graph. It then uses this graph to verify memory safety and construct symbolic output expressions for functional equivalence checking. While SentryWard generally assumes tensor shapes and kernel launch configurations are given and unrolls loops, it uses compact representations of repeated structures across threads and tensor computations to improve scalability. SentryWard is publicly available at https://github.com/gpu-verifier/sentryward.

</details>


### [3] [An Efficient and Uniform CSP Solution Generator Generator](https://arxiv.org/abs/2611.34372)
*Ghiles Ziat,Martin Pépin*

Main category: cs.PL

TL;DR: 论文研究如何为CSP的解构造均匀、高效的随机生成器：提出一种专用求解方法（基于超图表示的传播方案 + bridge-first分裂启发式），产出适合随机采样的表示，生成器由构造保证均匀、迭代且可自改进，并在AbSolute求解库上实现原型验证。


<details>
  <summary>Details</summary>
Motivation: 基于约束的随机测试需先给出性质、再提供输入生成器；而函数输入往往须满足约束才能保证正确运行，手工构造此类生成器困难。论文聚焦于为CSP解集自动制造均匀且高效的生成器。

Method: 采用面向随机采样的专用求解方法：基于CSP的超图表示设计专门的传播机制，并配套一种自定义分裂启发式（bridge-first）以强化该传播机制的效果；求解后所得表示可直接支撑均匀随机采样。

Result: 在AbSolute约束求解库上构建原型，并在多个实际案例上展示了性能表现。

Conclusion: 所构造的生成器具有足够通用性以覆盖广泛用例，且由构造保证均匀性、支持迭代与自我改进，为约束式随机测试中的输入生成提供了可行方案。

Abstract: Constraint-based random testing is a powerful technique which aims at generating random test cases to verify functional properties of a program. Its objective is to determine whether a function satisfies a given property for every possible input. This approach requires firstly defining the property to satisfy, then secondly to provide a generator of inputs able to feed the program with the inputs generated. Besides, function inputs often need to satisfy certain constraints to ensure the function operates correctly, which makes the crafting of such a generator a hard task. In this paper, we are interested in the problem of manufacturing a uniform and efficient generator for the solutions of a CSP. In order to do that, we propose a specialized solving method that produces a well-suited representation for random sampling. Our solving method employs a dedicated propagation scheme based on the hypergraph representation of a CSP, and a custom split heuristic called birdge-first that emphasizes the interests of our propagation scheme. The generators we build are general enough to handle a wide range of use-cases. They are moreover uniform by construction, iterative and self-improving. We present a prototype built upon the AbSolute constraint solving library and demonstrate its performances on several realistic examples.

</details>
