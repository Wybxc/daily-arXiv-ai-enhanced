### [1] [Towards Formal Verification of Hybrid Synchronous Programs with Refinement Types](https://arxiv.org/abs/2605.04377)
*Serra Z. Dane,Jiawei Chen,Marc Pouzet,Jean-Baptiste Jeannin*

Main category: cs.PL

TL;DR: 本文针对安全关键型信息物理系统（如自动驾驶汽车、飞机、机器人），提出了一种将同步编程语言与微分方程相结合的混合系统形式化验证方法。作者形式化了初值问题和过零检测的操作语义，扩展了类型系统以支持验证，并证明了其可靠性。


<details>
  <summary>Details</summary>
Motivation: 信息物理系统（如自动驾驶汽车、飞机、机器人）通常是安全关键的，必须高度确定地按预期运行。形式化验证虽被用于验证控制软件，但由于系统复杂性，通常仅在抽象模型而非可执行代码上进行。同步编程语言结合微分方程既能进行严格建模，又具备实现可执行控制器代码的足够表达能力，但现有验证技术仅适用于严格离散时间程序，需要将其扩展到混合系统以支持更广泛程序的验证与执行。

Method: 1) 形式化了同步编程语言中初值问题（IVP）和过零检测的操作语义；2) 扩展了该语言的类型系统以支持混合系统的形式化验证；3) 证明了所提出方法的可靠性（soundness）。

Result: 成功将离散时间程序的验证技术扩展到混合系统，实现了对包含连续动态环境建模的同步程序的验证与执行。

Conclusion: 通过形式化语义和类型系统的扩展，使得同步编程语言能够同时支持混合系统的形式化验证和可执行代码生成，弥合了抽象模型验证与可执行代码之间的鸿沟。

Abstract: Cyber-physical systems (CPS) such as autonomous cars, aircraft, and robots are often also safety-critical; thus it is imperative that they operate as intended with a high degree of certainty. Formal verification has been employed to verify the software controlling these systems, but due to their complexity, is usually performed on an abstract model rather than the executable code. Synchronous programming languages extended with differential equations promise both rigorous modeling and sufficient expressiveness to implement executable controller code, and recent developments have introduced formal verification of strictly discrete-time programs. Extending these verification techniques to hybrid systems enables precise modeling of the environment for a wider variety of programs to be both verified and executed. We formalize the operational semantics of initial value problems and zero-crossing detection expressed in a synchronous programming language, extend its type system for verification thereof, and prove its soundness.

### [2] [Interaction Tree Semantics for RISC-V: Bridging Compiler and Hardware Verification](https://arxiv.org/abs/2605.04933)
*Shuanglong Kan,Sebastian Ertel*

Main category: cs.PL

TL;DR: 本文提出了一个基于Interaction Trees (ITrees)的RISC-V ISA形式化语义，在Rocq证明助手中实现，支持从编译器IR到硬件的跨层级验证，并通过双模拟、提炼精化、可执行模拟器及三个案例研究（LLVM IR等价性证明、指令重排序验证、硬件ALU实现正确性证明）验证了其有效性。


<details>
  <summary>Details</summary>
Motivation: ISA是编译器与处理器之间的契约，但现有RISC-V形式化规范聚焦于硬件工具链，缺乏机器检验的指令级属性和跨层级验证支持，无法形式化证明编译器与硬件实现之间的契约关系。

Method: 在Rocq证明助手中基于Interaction Trees (ITrees)构建RISC-V ISA形式化语义，利用ITree双模拟(bisimulation)和精化(refinement)实现统一框架下的跨层级验证；覆盖广泛RISC-V扩展，每条指令语义通过机器检验引理保证正确性，并提取可执行模拟器通过标准RISC-V测试套件。

Result: 提取的可执行模拟器通过所有标准RISC-V测试套件；三个案例研究验证了跨层级验证的有效性：1) 基于双模拟证明LLVM IR与RISC-V代码在数组访问模式上的语义等价性；2) 对宏操作融合中的指令重排序进行翻译验证，区分安全重排序与破坏PC相对寻址的重排序；3) 证明Kôika硬件ALU正确实现了所有R-type整数操作（ADD, SUB, AND等）。

Conclusion: 基于ITrees的RISC-V形式化语义成功弥补了现有规范在跨层级形式化验证方面的不足，为编译器与处理器之间的契约提供了可机器检验的形式化保障，并通过案例证明了其在编译器到硬件全链验证中的实际效用。

Abstract: The Instruction Set Architecture (ISA) is the contract between compilers and processors; proving this contract formally demands cross-level connection to existing mechanized compilers and hardware implementations. As an open, modular ISA gaining adoption across embedded, mobile, and cloud platforms, RISC-V makes a formally verified ISA specification particularly valuable. However, existing formal RISC-V specifications focus on hardware tooling rather than cross-level verification: they provide no machine-checked instruction-level properties and lack support for verifying this contract across levels.
  We address these limitations with a formal semantics of the RISC-V ISA in Rocq, built on Interaction Trees (ITrees). By leveraging ITree bisimulation and refinement, our semantics enables cross-level verification from compiler IR to hardware within a single framework. Our formalization covers a wide spectrum of RISC-V extensions. The correctness of individual instruction semantics is backed by machine-checked lemmas in Rocq. We further validate it by extracting an executable simulator that passes all standard RISC-V test suites. Three case studies demonstrate the effectiveness of our semantics for cross-level verification: first, we prove semantic equivalence via bisimulation between LLVM IR and RISC-V code on an array access pattern via Vellvm (LLVM ITree semantics); second, we apply translation validation to a specific instruction reordering for macro-operation fusion, distinguishing safe reorderings from those that break program-counter-relative addressing; third, we prove that a Kôika hardware ALU correctly implements all R-type integer operations (e.g., ADD, SUB, AND) against our ISA contract.
