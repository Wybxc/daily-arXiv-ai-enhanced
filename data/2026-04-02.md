### [1] [Transformers for Program Termination](https://arxiv.org/abs/2604.00039)
*Yoav Alon,Cristina David*

Main category: cs.PL

TL;DR: 基于Transformer的集成学习框架用于程序终止性分析，通过不平衡感知损失函数和类别感知采样技术，显著优于单个Transformer模型、现成LLM和图方法


<details>
  <summary>Details</summary>
Motivation: 程序终止性判定是程序分析的核心挑战，直接影响正确性、验证和安全性。现有方法面临非终止样本极度稀缺的问题，需要探索Transformer架构是否能直接从源代码识别终止模式

Method: 设计紧凑Transformer编码器的集成框架，系统性地使用不平衡感知损失函数套件和类别感知采样技术进行训练。通过组合使用不同损失函数训练的模型，构建集成系统

Result: 集成方法显著优于任何单个Transformer模型，超越了强大的现成LLM和图方法。同时引入了能够生成语法感知解释的归因管道，为终止估计提供可解释性

Conclusion: Transformer架构能够有效识别程序终止模式，通过集成学习和专门设计的不平衡处理技术可以显著提升性能，为程序终止性分析提供了新的有效方法

Abstract: Determining whether a program terminates is a core challenge in program analysis with direct implications for correctness, verification, and security. We investigate whether transformer architectures can recognise termination patterns directly from source code and how their strengths can be amplified through ensembles. To overcome the extreme scarcity of non-terminating examples, we design an ensemble framework of compact transformer encoders, systematically trained with a suite of imbalance-aware loss functions and class-aware sampling techniques. By combining models trained with distinct loss functions, our ensembles achieve substantially stronger performance than any single transformer, outperforming both powerful off-the-shelf LLMs and graph-based methods. Finally, we introduce an attribution pipeline that produces syntax-aware explanations for the termination estimation.

### [2] [DriftScript: A Domain-Specific Language for Programming Non-Axiomatic Reasoning Agents](https://arxiv.org/abs/2604.00043)
*Seamus Brady*

Main category: cs.PL

TL;DR: DriftScript是一个Lisp风格、编译到Narsese的领域特定语言，旨在解决NARS输入语言Narsese的可读性和可用性问题。


<details>
  <summary>Details</summary>
Motivation: 标准NARS输入语言Narsese存在可用性障碍：其密集的符号表示、过载的标点和隐式约定使得程序难以阅读、编写和维护，这阻碍了NARS框架的实际应用。

Method: 设计DriftScript作为Lisp风格的领域特定语言，提供覆盖NAL 1-8级主要句子和术语形式的源级构造，用可读的关键字S-表达式替换符号语法。实现一个零依赖、四阶段管道的C99编译器（1941行代码），并与DriftNARS引擎集成，通过四种结构化回调类型和HTTP操作注册支持感知-推理-行动循环。

Result: 通过106个测试用例的测试套件、与手写Narsese的等价性测试、NAL覆盖分析、结构可读性指标和编译基准评估编译器。DriftScript成功解决了Narsese的可读性问题，同时保持了与NARS推理系统的兼容性。

Conclusion: DriftScript显著改善了NARS编程体验，通过提供更可读的语法和结构化接口，使构建自适应智能体更加可行。该语言专注于NARS的可用性改进而非新的推理算法，为NARS的实际应用提供了重要工具。

Abstract: Non-Axiomatic Reasoning Systems (NARS) provide a framework for building adaptive agents that operate under insufficient knowledge and resources. However, the standard input language, Narsese, poses a usability barrier: its dense symbolic notation, overloaded punctuation, and implicit conventions make programs difficult to read, write, and maintain. We present DriftScript, a Lisp-like domain-specific language that compiles to Narsese. DriftScript provides source-level constructs covering the major sentence and term forms used in Non-Axiomatic Logic (NAL) levels 1 through 8, including inheritance, temporal implication, variable quantification, sequential conjunction, and operation invocation, while replacing symbolic syntax with readable keyword-based S-expressions. The compiler is a zero-dependency, four-stage pipeline implemented in 1,941 lines of C99. When used with the DriftNARS engine, DriftScript programs connect to external systems through four structured callback types and an HTTP operation registry, enabling a sense-reason-act loop for autonomous agents. We describe the language design and formal grammar, detail the compiler architecture, and evaluate the compiler through a 106-case test suite, equivalence testing against hand-written Narsese, a NAL coverage analysis, structural readability metrics, and compilation benchmarks. The source code is available at https://github.com/seamus-brady/DriftNARS. This paper focuses on the design and implementation of the DriftScript language and its embedding into DriftNARS, rather than on new inference algorithms for NARS itself.

</details>
