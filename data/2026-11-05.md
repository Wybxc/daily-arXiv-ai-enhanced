### [1] [Demystifying Information Flow Downgrading using the Real--Ideal Paradigm](https://arxiv.org/abs/2611.05695)
*Suraaj Kanniwadi,Andrew C. Myers*

Main category: cs.PL

TL;DR: 本文提出以密码学中的real–ideal范式为基础，构建一个新的、强大且直观的基于语言安全的语义框架，可外延地统一刻画非干扰、鲁棒脱密、不可篡改信息流等安全性质，并用一个实用的信息流类型系统对这些性质进行静态强制执行。


<details>
  <summary>Details</summary>
Motivation: 现有基于语言的安全定义（尤其是涉及降密/downgrading的信息流性质，如鲁棒脱密和不可篡改信息流）多依赖内蕴式的降密事件（intensional downgrading events），缺乏统一、外延的语义刻画，且这些性质的实用性与相互关系尚不清楚。

Method: 将real–ideal范式引入语言安全语义：以理想（ideal）系统与真实（real）系统之间的模拟关系定义安全。据此统一刻画非干扰及各类降密性质；进而设计一个支持降密的信息流类型系统，用于while语言，并将该类型系统的正确性也刻画为real–ideal模拟。

Result: 证明该框架可干净且外延地捕获既有安全定义（非干扰、鲁棒脱密、不可篡改信息流），且这些性质均可由实用类型系统强制执行；类型系统正确性等价于real–ideal模拟，从而表明：具有强（真实）攻击者的异构去中心化系统的安全性，可通过推理力量受限（仅能与降密交互）的弱（理想）攻击者来理解。

Conclusion: real–ideal范式为语言安全提供了统一、直观且可机械化的语义基础，解释了不可篡改信息流及相关性质的有用性；所有结果均在Rocq证明助手中完整形式化并公开。

Abstract: The real--ideal paradigm, an approach to security specification developed in the cryptography community, has the benefit that it can express sophisticated confidentiality and integrity requirements, even for decentralized systems. We show that this paradigm is the basis for a powerful and intuitive new semantic framework for language-based security. Our new framework cleanly and extensionally captures existing security definitions, including not only noninterference but also less understood information flow properties that involve downgrading, such as robust declassification and nonmalleable information flow. Past semantics for these properties have relied on intensional downgrading events. Further, we show that all of these properties can be enforced by a practical information-flow type system for a while-language that supports downgrading. Surprisingly, correctness of this type system is also characterized as a real--ideal simulation, with an important implication: the security of heterogeneous, decentralized systems with a strong (real) attacker can be understood by reasoning about a weak (ideal) attacker whose power is restricted to interaction with downgrading. This result explains the usefulness of nonmalleable information flow and related security properties. The results are fully formalized using the Rocq prover and are publicly available.

### [2] [TauLang: A Language and Compiler for Space-Time Programming on Statically Scheduled Accelerators](https://arxiv.org/abs/2611.06079)
*Xuxiao Yang,Junchi Wu,Feiyang Wu,Zhuoran Li,Shuo Tao,Dongyi Fan,Yiming Zhang,Keqin Luo,Xingrui Gao,Xuehai Qian,Youwei Zhuo*

Main category: cs.PL

TL;DR: TauLang 将"时间"提升为程序一等公民：程序员用参数化显式时间标注操作、循环与组合核，编译器经 TauIR 代数校验时间并用 ILP 联合求解张量放置与周期调度，在类 TSP 机器上相比 space-first 流程获得 1.40× 延迟加速。


<details>
  <summary>Details</summary>
Motivation: 静态调度加速器（如 Groq TSP）剔除动态同步硬件以获得低延迟 LLM 推理，因此每个操作的切片与发射周期必须由编译器完全固定，"何时执行"成为正确性条件。现有核语言依赖硬件解决周期时序、只能把调度隐式编码在代码结构中，无法面向此类机器。

Method: 提出 TauLang 核语言与编译器：以参数化显式时间调度操作、循环和组合核，改调度即改参数而非重写代码；在定时的中间表示 TauIR 中对显式时间做代数校验；随后以整数线性规划（ILP）联合求解张量放置与周期调度，利用显式时间把相连操作聚成 timing cluster 以剪枝搜索空间。

Result: 在类 TSP 机器的周期精确模型上，联合搜索在十个核上相较 space-first 流程取得 1.40× 延迟加速；少量显式时间 pin 可将延迟保持在无定时调度的一个周期以内，并将联合搜索扩展到 1,636 个 GEMM 块，而无定时搜索在 32 个块时即找不到可行调度。

Conclusion: 将时间显式化、参数化并纳入编译器求解，是面向静态调度加速器的可行且高效的核语言设计路线，兼顾可编程性、可扩展性与调度质量。

Abstract: Statically scheduled accelerators such as Groq's Tensor Streaming Processor (TSP) achieve low-latency large language model inference by stripping dynamic synchronization hardware from the chip. With no caches, arbiters, or hardware schedulers, the compiler must fix the exact slice and issue cycle of every operation, so when an operation runs is a condition for correctness. Existing kernel languages cannot target such machines because they rely on hardware to resolve cycle timing and instead encode schedules implicitly in code structure. We present TauLang, a kernel language and compiler that makes time a first-class citizen of the program. The programmer schedules operations, loops, and composed kernels with parameterized explicit times, so exploring schedules means changing parameter values rather than rewriting code. TauLang validates explicit times algebraically in TauIR, its timed intermediate representation. It then solves tensor placement and cycle scheduling jointly in an integer linear program, using explicit times to group connected operations into timing clusters that prune the search space. On a cycleaccurate model of a TSP-like machine, joint search achieves a $1.40\times$ latency speedup across ten kernels over a space-first flow. A few explicit time pins keep latency within one cycle of the untimed schedules and scale joint search to 1,636 GEMM blocks, whereas untimed search finds no schedule at 32.

</details>


### [3] [Verified Implementation of the Next-gen Borrow Checking Algorithm for Rust via Abstract Interpretation](https://arxiv.org/abs/2611.06319)
*Jinhua Wu,Yuting Wang,Zhemin Chen*

Main category: cs.PL

TL;DR: 首次将 Rust 编译器中的 Polonius 借用检查算法形式化为基于抽象域（记录指针别名/借用关系）的正向抽象解释，在 CompCert 抽象解释框架中实现并验证，证明任何被 Polonius 接受的程序运行时都不会访问失效引用，从而导出内存安全。


<details>
  <summary>Details</summary>
Motivation: Rust 借用检查的正确性直觉依赖"别名 XOR 可变性"（Aliasing XOR Mutability）保证无借用错误即无失效引用访问。但已有工作要么把借用检查当作类型系统的一部分，要么用符号执行描述资源转移，均无法直接解释 NLL、Polonius 这类"更像静态指针分析"的官方算法为何正确。该文旨在填补这一空白。

Method: 在 Rust 核心子集上形式化下一代借用检查算法 Polonius。关键观察：当借用检查以惰性（lazy）方式执行时，Polonius 可视为在记录指针别名（借用）关系的抽象域上的正向抽象解释。为此给出一个形式刻画"别名 XOR 可变性"纪律的具体语义，证明该抽象解释的可靠性（soundness），进而推出被检查程序的内存安全。形式化在 CompCert 抽象解释框架中实现与机器验证，证明脚本由人类引导的 agentic AI 以论文证明为大纲生成。

Result: 建立了 Polonius 的抽象解释表述并在 CompCert 框架内完成实现与形式验证；证明任何经 Polonius 接受的程序不会在运行时访问失效引用，由此得到内存安全结论。据作者所知，这是首个对 Rust 编译器中实际借用检查算法的全面形式化与验证工作。

Conclusion: 借用检查可被统一理解为抽象解释，从而为其算法正确性提供直接解释；该视角把 Rust 的内存安全保证纳入经过验证的抽象解释框架，为后续覆盖更完整 Rust 子集与算法（如 NLL）的验证奠定基础。

Abstract: Borrow checking is a central mechanism for Rust to ensure temporal memory safety. Its correctness is based on the intuition that the Aliasing XOR Mutability discipline guarantees that programs without borrow errors inherently could not access invalid references (i.e., pointers). However, existing work on formalizing borrow checking treats it either as a component of type systems or as symbolic execution describing resource transfer. None provides a direct explanation of the correctness of borrow checking algorithms such as Non-Lexical Lifetimes (NLL) or Polonius in the official Rust compiler that function more like static pointer analysis.
  We take a first step toward solving this problem by formalizing Polonius, the next-generation borrow- checking algorithm for the Rust compiler, on a core subset of Rust. We prove its correctness by showing that any program accepted by Polonius does not access invalid references at runtime. The key observation is that, when borrow checking is performed lazily, Polonius could be treated as a forward abstract interpretation on abstract domains recording pointer aliasing (borrowing) relations. By providing a concrete semantics that formally describes the Aliasing XOR Mutability discipline, we prove the soundness of this abstract interpretation, from which we derive memory safety of checked programs. This formulation of Polonius is implemented and formally verified in the abstract interpretation framework of CompCert. The correctness proofs are generated by an agentic AI under human guidance using paper proofs as proof outline. To the best of our knowledge, this is the first comprehensive formalization and verification of a borrow checking algorithm as manifested in the Rust compiler.

</details>
