Abstract: Developing quantum programs requires not only running them on quantum hardware but also simulating them on classical hardware. Because the meaning of a quantum program can be defined in terms of state vectors, it can be viewed as a form of weighted nondeterminism and simulated using any implementation of probabilistic programming that supports complex or at least negative weights. In this study, we compile a high-level quantum programming language to one such implementation of probabilistic programming, a solver for factor graph grammars. We also extend the solver with an optimization that commutes the tensor operations $\mathsf{einsum}$ and $\mathsf{expand}$. We prove that the compiler and the optimization preserve the denotational semantics of the source language. We perform benchmarks that show our straightforward implementation, by repurposing existing infrastructure for probabilistic programming, attains simulation performance in the ballpark of several other quantum simulators.

### [3] [A Compilation Model for Divergent Parallel Workloads](https://arxiv.org/abs/2611.22183)

TL;DR: 提出"并行调度图"编译模型，将分歧并行程序的优化视为可组合的已知程序变换，并用调度语言分离算法与执行策略，在空间计算应用上匹配或超越手工优化实现（几何平均1.02–2.95×）。

Method: 指出加速分歧并行程序的关键优化可表述为函数式编程与循环优化社区中已知变换的组合；据此提出并行调度图（parallel dispatch graphs）编译模型，在单一抽象中表示控制流、逻辑阶段间数据流与并行循环；并设计调度语言，包含数据依赖控制流/数据流的可组合变换、标准循环变换及硬件绑定，实现算法核心与执行调度的关注点分离。

Conclusion: 将分歧并行优化统一为已知程序变换的组合，并通过调度语言实现算法可移植性与执行策略特化，是可行且有效的编译方法；不存在普适最优调度，需针对程序、硬件与输入数据自适应选择。

Abstract: Efficient execution on modern parallel machines requires more than abundant parallelism; it demands instruction coherence, memory coherence, and load balance to maximize SIMD utilization and memory bandwidth. Efficiently mapping \textit{divergent} parallel workloads to modern machines, where control flow, memory accesses, and unbounded iteration depend on per-thread runtime values, often requires global program restructuring that trades off increased coherence with reduced locality, parallelism, or extra work. We observe that the key optimizations used to accelerate divergent parallel programs can be expressed as compositions of well-known program transformations from the functional programming and loop optimization communities. We operationalize this insight through \textit{parallel dispatch graphs}: a compilation model that represents divergent programs by representing control flow, data flow between logical stages, and parallel loops within a single abstraction. To facilitate rapid exploration of points in the optimization space, we provide a scheduling language that includes composable transformations of data-dependent control flow and data flow, together with standard loop transformations and hardware bindings. This separation of concerns allows the core algorithm to remain portable, while the execution schedule can be specialized to the specifics of target hardware and input data values. We evaluate our system using popular applications from the domain of spatial computing, and show that the optimization strategies of hand-optimized parallel tree traversals, path tracers, and Monte Carlo PDE solvers can be reproduced as schedules in our system. Our generated code matches or outperforms the hand-optimized implementations (geomeans $1.02$--$2.95\times$ faster). Additionally, we demonstrate empirically that the best schedule varies across programs, machines, and inputs.
