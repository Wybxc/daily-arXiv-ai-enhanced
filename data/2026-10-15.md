### [1] [Recursive Formation and First-Class Reuse of Compositional Capabilities](https://arxiv.org/abs/2610.19414)
*Hang Lin*

Main category: cs.PL

TL;DR: 本文提出 FormCraft 框架，将获取的操作表示为可递归组合、直接调用并选择性持久保留的一等能力，并通过领域特定验证支持复用。


<details>
  <summary>Details</summary>
Motivation: 现有系统中的操作或技能通常难以作为一等实体被递归组合、独立验证和持久化复用，历史形成过程与运行身份也容易混淆。

Method: FormCraft 将能力良构性与公共可调用性同持久存储准入分离，同时保留形成来源与操作身份；形式化统一能力空间上的递归组合闭包，使组合体可通过同一公共接口复用而无需重新执行历史推导；并在连续、离散、命题和序列领域开展实验。

Result: 实验表明，一等暴露下可实现实例无关复用、独立检查、持久获取，并减少复用时的搜索开销。

Conclusion: FormCraft 为可组合、可验证、可持久复用的操作能力提供了一种统一表示与运行时框架。

Abstract: We introduce FormCraft, a framework for representing acquired operations as first-class capabilities that can be recursively composed, directly invoked, and selectively retained in a persistent library through domain-specific verification. The framework separates capability well-formedness and public callability from later admission to persistent storage while preserving formation provenance and operational identity. We formalize recursive compositional closure over a uniform capability space and show that formed composites can be reused through the same public interface without re-forming their historical derivation. Experiments across continuous, discrete, propositional, and sequence domains demonstrate instance-independent reuse, independent checking, persistent acquisition, and reduced reuse-time search work under first-class exposure.

### [2] [Verifying deployed bytecode against executable EVM semantics, with exact gas and no added axioms](https://arxiv.org/abs/2610.19764)
*Seulkee Baek*

Main category: cs.PL

TL;DR: 提出 Lean 4 验证栈 Blanc，可直接验证不可变 EVM 字节码（含未验证编译器输出），基于可执行语义 Jaune，在无额外公理下对 EIP-7002、Uniswap V2、WETH9、Curve 等已部署合约完成形式化证明。


<details>
  <summary>Details</summary>
Motivation: 以太坊最具影响力的代码多为不可变字节码（旧编译器输出、作为合约代码运行的协议逻辑），传统验证需信任生产者或简化机器。作者希望在不信任编译器、不简化 EVM、不加额外公理的前提下，直接对该字节码本身进行验证。

Method: 构建 Lean 4 验证栈 Blanc，通过内核校验的证书读取固定运行时字节；所有定理针对 Jaune——EVM 与区块处理的可执行语义，该语义通过 fixture v20.0.2 中相关分叉的全部 34,205 个区块链测试用例。对 8 个 2017–2026 年部署、来自 7 个编译器版本与 1 个汇编器的制品进行验证，证明由 AI agent 在 15 天内、按一位作者指导在既有栈上完成。

Result: 对 EIP-7002 证明区块末调用必成功且提款请求恰为最旧待处理提交；对 Uniswap V2 pair 证明存储精确表示模型在已提交调用上的重放、流动性账本平衡、协议费下每份额几何平均储备仅下降；利用精确 gas 证明 WETH9 持有者提款交易 gas 有闭式解，与 3,748 笔主网收据吻合；对含 2023 漏洞的 Curve 字节码，Jaune 从部署起即可执行该重入，而固定编译器字节码下证明锁可排除重入。

Conclusion: Blanc 表明可直接对已部署的不可变字节码进行端到端形式化验证，无需信任编译器、不简化 EVM 且不引入额外公理；精确 gas 分析使活性可证，并能复现与排除真实漏洞。

Abstract: Much of Ethereum's most consequential code is immutable bytecode: old output of unverified compilers, and protocol logic run as contract code. We show that such bytecode can be verified as it is, without trusting what produced it, without simplifying the machine it runs on, and with no axioms beyond Lean's own. Blanc, a Lean 4 verification stack, reads fixed runtime bytes via kernel-checked certificates and states every theorem against Jaune, an executable semantics of the EVM and block processing that passes all 34,205 blockchain-test cases of Ethereum's fixture release v20.0.2 that involve only forks that have governed mainnet since May 2025. Eight artifacts, deployed from 2017 to 2026, come from seven compiler versions and an assembler. For the EIP-7002 contract, we prove that the end-of-block call to it, whose failure would invalidate the block, succeeds whatever its storage holds, and that each block's withdrawal requests are exactly the oldest pending submissions; mainnet met these theorems' starting premises when Prague began. For a Uniswap V2 pair, we prove that after any valid history whose hashed slots stay apart, from any checkpoint representing its Solidity model's state, the storage represents that model replayed over exactly the committed calls, a balanced liquidity ledger stays balanced, and, under a premise on token answers, geometric-mean reserves per share fall only through the protocol fee. Exact gas makes liveness provable: a tracked WETH9 holder without code can withdraw by a transaction whose gas has a closed form, matching all 3,748 comparable mainnet receipts of its shape in 30,000 blocks. On Curve pool bytes compiled with the lock bug exploited in 2023, Jaune executes such a reentrancy from deployment; for bytes from a fixed compiler, we prove the lock excludes it. AI agents wrote the proofs in fifteen days under one author's direction, atop an existing stack.

### [3] [Typechecking without Minimum Types: Finite Bases and Backward Checking for $F_{<:}^{\top}$](https://arxiv.org/abs/2610.20356)
*Mingkun Xiao,Yixuan Sun*

Main category: cs.PL

TL;DR: 该论文研究 System F_{<:}^{⊤} 的类型检查可判定性，证明任意显式标注项在无限制 subsumption 下类型检查可判定，并给出两种总函数式实现与工作量界。


<details>
  <summary>Details</summary>
Motivation: System F_{<:}^{⊤} 的 subtyping 可判定，但缺少 minimum types（最小类型），因此无法直接沿用基于最小类型的类型检查算法。同时，类型抽象使用变量声明上界来类型化其体，而量化 subtyping 会遗忘该上界，这一上下文变化使算法设计困难。

Method: 构造有限 covers，在上下文变化中保留所有必需的 subtype 比较，从而得到可组合的有限 typing basis 与判定过程；进一步导出向后检查器（backward checker），无需构造完整 typing basis 即可传播可接受目标。利用 typing families 的矩形性（rectangularity）给出统一消去域并保留所有结果类型；通过有限逆族（inverse families）在类型替换下传输目标，同一逆规范同时恢复 bound forgetting 并产生有限 type-avoidance families。

Result: 两种类型检查过程均实现为总 Rocq 函数，并证明与原 typing judgment 等价；针对独立的符号 word-RAM 实现，证明了四次方（quartic）最坏情况工作量界；在独立 OCaml 原型上测量了 synthetic checking judgments 的族表示规模与比较存储开销。

Conclusion: 该工作解决了 F_{<:}^{⊤} 在缺乏 minimum types 情形下的类型检查可判定性问题，给出可验证、可实现的算法框架，并为实际实现提供复杂度与空间开销的实证数据。

Abstract: System $F_{<:}^{\top}$ has decidable subtyping but lacks minimum types. We prove that typechecking is decidable for arbitrary explicitly annotated terms with unrestricted subsumption. The difficulty is that type abstraction uses a variable's declared bound to type its body, while quantified subtyping forgets that bound. We construct finite covers that preserve all required subtype comparisons across this change of context. These covers yield a compositional finite typing basis and a decision procedure.
  We then derive a backward checker that propagates acceptable targets without constructing the complete typing basis. Rectangularity of typing families gives a uniform elimination domain while retaining every result type, even when the canonical type is not least. Finite inverse families transport targets through type substitution. The same inverse specification recovers bound forgetting and yields finite type-avoidance families. Both typechecking procedures are total Rocq functions proved equivalent to the original typing judgment. For a separate symbolic word-RAM realization, we prove a quartic worst-case work bound. We measure family representation sizes and comparison storage in independent OCaml prototypes on synthetic checking judgments.

</details>
