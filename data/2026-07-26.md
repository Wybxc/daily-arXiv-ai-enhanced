### [1] [Imprecise Probabilistic Programming, Precisely: Credal Sets via Graded Monads, BDDs, and Semiring-Parametric Inference (Functional Pearl)](https://arxiv.org/abs/2607.20801)
*Jack Liell-Cock,Sam Staton*

Main category: cs.PL

TL;DR: 本文提出不精确概率可通过将BDD变量权重保留为自由参数而非固定值来实现，并设计了Imp语言——基于Haskell的嵌入式DSL，利用分级单子恢复交换性，支持精确、可微和区间边界三种推理模式。


<details>
  <summary>Details</summary>
Motivation: 标准概率语言中的BDD编译和加权模型计数管道无法直接处理不精确概率（用凸集代替单一分布），需要扩展以支持 epistemic 不确定性下的推理。

Method: 1) 将不精确硬币翻转建模为权重自由的BDD变量；2) 设计Imp DSL，采用按有限命名源索引的分级单子（graded monad）恢复交换性；3) 利用GHC类型系统在编译期保证正确性；4) 基于半环参数化的加权模型计数实现多模式推理。

Result: 同一编译后的BDD可同时支持精确推理、可微推理和区间边界推理三种推断方式。

Conclusion: 不精确概率的引入不需要改变标准BDD编译和加权模型计数流程，仅需将权重参数化即可，Imp语言通过类型系统确保了安全性和灵活性。

Abstract: Imprecise probability generalizes standard probability theory by replacing a single distribution with a convex set of possible distributions. We show that this generalization requires no change to the standard BDD compilation and weighted model counting pipeline used by discrete probabilistic languages. An imprecise coin flip is simply a BDD variable whose weight is left free rather than fixed. We introduce Imp, a Haskell-embedded DSL for imprecise probabilistic programming. A graded monad, indexed by finite sets of named sources of epistemic uncertainty, restores the commutativity that the standard convex powerset monad lacks, and GHC's type system enforces this at compile time. Weighted model counting is parametric in the semiring, so the same compiled BDD supports exact, differentiable, and interval-bounded inference.

### [2] [GLP: A Grassroots, Multiagent, Concurrent, Logic Programming Language for AI](https://arxiv.org/abs/2607.21189)
*Ehud Shapiro*

Main category: cs.PL

TL;DR: 本文提出了一种名为Grassroots Logic Programs (GLP)的多智能体并发逻辑编程语言，用于实现草根平台。GLP通过限制标准逻辑程序的并发操作语义，结合多智能体原子事务，证明了其草根性（即多独立实例可独立运行、合并，无需全局资源）。草根社交图作为示例展示了GLP的编程应用。


<details>
  <summary>Details</summary>
Motivation: 草根平台旨在提供一种平等/民主的替代方案，以对抗中心化/专制和去中心化/财阀统治的全球平台。需要一种专门的语言来设计和实现这种多智能体分布式系统。

Method: 基于标准逻辑程序的操作语义，引入GLP的并发操作语义作为其限制；回顾多智能体原子事务；利用它们引入GLP的多智能体操作语义；并证明多智能体GLP具有草根性。

Result: GLP被证明是草根的——多个独立实例可以独立形成和运行，互不依赖且不依赖任何全局资源，同时可以合并成更大的实例甚至全局实例。

Conclusion: GLP是一种有效的多智能体并发逻辑编程语言，能够用于实现草根平台，为构建平等/民主的分布式系统提供了理论基础和编程范式。

Abstract: A grassroots platform is a multiagent distributed system in which multiple independent instances can form and operate independently of each other and of any global resource, yet may coalesce into ever larger instances, possibly resulting in a single global instance.  Grassroots platforms aim to offer an egalitarian/democratic alternative to  centralised/autocratic and decentralised/plutocratic global platforms.
  Here, we present Grassroots Logic Programs (GLP), a multiagent concurrent logic programming language designed for the implementation of grassroots platforms:  we recall the standard operational semantics of logic programs; introduce the concurrent operational semantics of   GLP as its restriction; recall multiagent atomic transactions; use them to introduce a multiagent operational semantics of GLP; and prove multiagent GLP to be grassroots. The grassroots social graph—the foundational grassroots platform on which all others are based—serves as a GLP programming example.

### [3] [chrKanren: Constraint Handling Rules in a Relational Language](https://arxiv.org/abs/2607.21204)

<details>
  <summary>Details</summary>
Motivation: 在纯关系逻辑编程语言 miniKanren 中缺乏原生支持约束求解和规则推理的能力，无法高效表达和求解复杂约束问题，因此需要将 CHR 集成进来以增强表达力和推理能力。

Method: 将 CHR 的约束传播机制纳入 miniKanren 的搜索流中，确保两者保持完整性和相容性；同时利用 chrKanren 实现语义合一、类型与示例引导的合成等新应用。

Result: 成功实现了一个兼具 miniKanren 关系编程和 CHR 约束推理能力的语言 chrKanren，并通过示例展示了其在语义合一和关系解释器合成方面的有效性。

Conclusion: chrKanren 扩展了 miniKanren 的约束处理能力，为关系编程中的复杂约束求解和程序合成提供了新的路径，具有理论和实践上的双重意义。

Abstract: We present chrKanren, a dialect of the purely relational constraint logic programming language miniKanren which includes support for Constraint Handling Rules (CHR), a language for writing rule-based programs such as constraint solvers. We show how to integrate CHR's constraint propagation mechanism into the language of miniKanren search streams such that both processes remain complete. We also use chrKanren to illustrate novel applications of constraints in miniKanren, such as semantic unification of user-defined data structures and type-and-example-directed synthesis for relational interpreters in the style of MYTH.

There is no resolution-based algorithm for handling integrity constraints that can be used in stableKanren. We implement CaVE using Scheme in stableKanren and show a series of example normal programs written in stableKanren with integrity constraints.

### [5] [Top-down = Bottom-up: Sound and Complete Characterisations of Liveness by Multiparty Global Protocols](https://arxiv.org/abs/2607.21489)
*Kai Pischke,Nobuko Yoshida*

Main category: cs.PL

TL;DR: 本文证明，在适当的子类型规则下，多会话类型（MPST）的两种主流方法——自顶向下（基于全局类型和端点投影）和自底向上（基于局部类型推断）——具有完全相同的类型可判定性（typability）。关键在于提出了一种主要全局类型推断算法，可将任意活着的局部类型集合自动综合为全局类型。实验表明自顶向下方法比自底向上方法更高效。


<details>
  <summary>Details</summary>
Motivation: 长期以来学术界普遍认为，自顶向下的MPST方法因为依赖全局类型和端点投影算法，其类型表达能力（typability）严格弱于自底向上方法。本文旨在推翻这一认知，证明两种方法具有等价的可判定能力。

Method: 提出一种主要全局类型（principal global type）推断算法，能够从任意一组满足活性（liveness）的局部类型中自动综合出对应的全局类型。在此基础上，利用精确子类型（precise subtyping）作为子类型规则，证明自顶向下和自底向上系统的可判定性等价。

Result: 证明了多会话M能被自底向上系统判定为活性的当且仅当M能被自顶向下系统判定。实现了包含全局类型推断、投影、进程类型检查和局部类型推断的完整工具链，并在代表性示例上验证了自顶向下方法比自底向上方法更高效。

Conclusion: 自顶向下与自底向上两种MPST方法具有完全相同的类型表达能力，且自顶向下方法在效率上更具优势。这一结论统一了两种主流方法，为MPST的理论和实践提供了新的基础。

Abstract: Multiparty session types (MPST) are a type discipline for concurrent and distributed systems, designed to ensure not only type safety and deadlock-freedom, but also liveness of typed communicating processes. Two main MPST methodologies, top-down and bottom-up, have been proposed and are integrated into a wide range of programming languages and tools. The top-down strategy starts by specifying the overall choreography of the protocol (called a global type), from which a set of local types that satisfy safety and liveness are generated by endpoint projection (EPP). Once each participant is type-checked against a generated local type, liveness of the set of typed processes is automatically ensured by construction. The bottom-up strategy directly checks whether local types inferred from processes satisfy liveness to enforce liveness of processes. Since the top-down strategy depends on global types and the EPP algorithms, it has often been considered that the top-down system offers strictly less typability than the bottom-up system. Our paper negates this belief. We prove that, using the precise subtyping for the subsumption rule, the top-down strategy offers exactly the same typability as the bottom-up system. More precisely, a multiparty session $M$ is typable and verified to be live by the bottom-up typing system if and only if $M$ is typable by the top-down typing system. The key to the proof is a principal global type inference algorithm which builds a principal global type from an arbitrary set of live local types. We have implemented the global type inference algorithm together with projection, process type checking and local type inference algorithms, and built a toolchain for both the top-down and bottom-up strategies. We evaluated our toolchain with representative examples from the literature, confirming that the top-down approach is more efficient than the bottom-up approach.

</details>
