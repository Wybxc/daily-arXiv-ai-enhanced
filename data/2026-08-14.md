### [1] [A Rig of Transformations](https://arxiv.org/abs/2608.12409)
*Emma Tye*

Main category: cs.PL

TL;DR: 本文提出将有限代数数据类型建模为交换rig（无加法逆元的环），用数据间的同构来建模rig等式，并可进一步将数据类型嵌入更大类型（如位填充）建模为偏同构，从而在高层函数式语言中使编译器能更好地控制数据的运行时表示。


<details>
  <summary>Details</summary>
Motivation: 高层函数式语言中，编译器通常很少让用户控制数据类型的运行时表示。然而程序层面的数据建模方式与二进制层面的表示方式常常不同（出于效率或遗产代码原因）。因此，能够描述数据布局及其变换对于编程而言是有用且必要的，但要正确、高效且符合人体工学地实现这一点非常困难。

Method: 将有限代数数据类型建模为一个交换rig（commutative rig，即无加法逆元的环），其中rig等式通过数据之间的同构来建模。此外，将数据类型嵌入更大类型（例如位填充bit-padding）建模为偏同构（partial isomorphism）。

Result: 本文给出了一个代数框架，将数据布局变换与数据类型同构联系起来，使用交换rig的代数结构统一刻画数据类型的组合与变换，并通过偏同构处理嵌入/填充等场景。

Conclusion: 该代数模型为在高层函数式语言中描述和推理数据布局变换提供了理论基础，使得数据表示的转换可以在类型层面被统一地建模和验证。

Abstract: In high-level functional languages, the compiler often gives users little control over the runtime representation of data types. Yet how we model data structures at the program level can be different to how we want to represent them at the binary level, for efficiency or legacy reasons. Hence being able to describe data layouts and their transformations for data types is a useful and necessary part of programming, but difficult to do correctly, efficiently and ergonomically. We present a model of finite algebraic data types as a commutative rig (a ring without additive inverses), where the rig-equalities are modelled by isomorphisms between data. Using this approach, we can also model embedding a data type into a larger type (e.g. bit-padding) as a partial isomorphism.

### [2] [Stream-based Online and Offline Monitoring under Measurement Noise](https://arxiv.org/abs/2608.13211)
*Bernd Finkbeiner,Martin Fränzle,Florian Kohn,Paul Kröger*

Main category: cs.PL

TL;DR: 本文提出RLola，一种基于流的规范语言Lola的鲁棒扩展，通过引入松弛变量（slack variables）符号化表示传感器测量噪声，避免区间算术的别名问题。文章给出在线和离线监控算法，在线监控可在保证常数内存的片段上运行，离线监控基于SMT求解器分析完整系统轨迹，检测在线监控可能遗漏的违规。算法已在RTLola框架中实现并验证。


<details>
  <summary>Details</summary>
Motivation: 流式监控是网络物理系统运行时验证的重要方法，但现有方法假设输入流值完全准确。实际上物理传感器存在测量噪声和误差，这些误差在监控器的处理和聚合步骤中被进一步放大。因此需要一种能够显式建模噪声、提供鲁棒监控的方案。

Method: 1) 在Lola语言基础上引入松弛变量，符号化表示测量噪声，避免区间算术的别名问题；2) 提出在线监控算法，并识别一个保证常数内存的丰富片段（rich fragment），可自动翻译为常数内存监控器；3) 提出基于SMT（satisfiability-modulo-theories）的离线算法，分析完整系统轨迹，判定是否存在满足所有断言的假设性ground-truth轨迹；4) 在现有RTLola框架中实现两种算法。

Result: 在线RLola监控器可实时反馈当前断言状态；离线SMT算法能检测在线算法可能遗漏的违规。算法已在RTLola框架中实现，并通过综合案例评估了其精度和运行时间。

Conclusion: RLola为流式监控提供了鲁棒的噪声建模能力，在线与离线算法互补：在线监控提供实时反馈，离线分析提供更完整的违规检测能力。这是对基于流的运行时验证在现实传感器噪声场景下可靠性的重要提升。

Abstract: Stream-based monitoring is a runtime verification approach for cyber-physical systems that translates streams of input data, such as sensor readings, into streams of aggregate statistics and verdicts about the safety of the system. It is usually assumed that the values on the input streams represent fully accurate measurements of the physical world. In reality, however, physical sensors are prone to measurement noise and errors. These errors are further amplified by the processing and aggregation steps within the monitor. This paper introduces RLola, a robust extension of the stream-based specification language Lola. RLola incorporates the concept of slack variables, which symbolically represent measurement noise while avoiding the aliasing problem of interval arithmetic.
  We present algorithms for both online and offline monitoring of RLola specifications. Since monitoring RLola specifications may require unbounded memory in general, we identify a rich fragment of RLola that can be automatically translated into monitors with guaranteed constant memory usage for online monitoring. An online RLola monitor observes a live system and provides real-time feedback on the current status of specified assertions. A satisfiability-modulo-theories-based offline algorithm analyzes complete system traces and determines whether a hypothetical ground-truth trace exists that satisfies all assertions at all time points. The offline algorithm can therefore detect violations that the online algorithm may miss. We implement these algorithms in the existing RTLola framework and evaluate their precision and running time based on a comprehensive example.

### [3] [Multiobjective Preexpectation Reasoning for Probabilistic Programs](https://arxiv.org/abs/2608.13268)
*Lena Verscht,Hannah Mertens,Kevin Batz,Sebastian Junges,Benjamin Lucien Kaminski,Joost-Pieter Katoen*

Main category: cs.PL

TL;DR: 本文提出了一种面向多目标强化学习/策略综合的演绎式程序级方法，通过多目标前置期望变换器（multiobjective preexpectation transformer）在凸Hoare幂域中同时优化多个目标，并采用混合确定化（mixed determinization）策略来综合见证策略，可处理无限状态MDP，不依赖有限状态空间假设。


<details>
  <summary>Details</summary>
Motivation: 传统概率程序分析通常只处理单目标优化，而现实中的规划问题往往需要同时优化多个目标（如成本与收益、时间与资源等），沿Pareto前沿进行权衡。已有的多目标方法多依赖有限状态空间或数值求解，缺少在程序级（语法级）上的演绎式（证明论）处理手段，因此作者希望在概率程序语言层面为多目标策略综合建立一套逻辑推理框架。

Method: 核心贡献是一个多目标前置期望变换器，它将一组后置期望元组映射为"可同时达成的值集合"，该集合是凸Hoare幂域的一个元素。该变换器保守地推广了经典的最弱前置期望（weakest preexpectation）理论，并提升了标准的循环规则。在此基础上，作者开发了综合见证策略的规则，这些策略为"混合确定化"——即在若干非概率确定化策略上做随机化。所有规则均针对操作性的MDP语义证明了其可靠性，且不要求状态空间有限，从而实现了一种程序级的符号化多目标优化方法。

Result: 作者证明所提出的变换器与策略综合规则对操作性的MDP语义是可靠的，支持无限状态空间下的多目标优化。通过多个案例研究展示了该机制的实际可行性与应用价值，印证了该方法能够处理超出传统有限状态假设的多目标规划问题。

Conclusion: 该工作建立了概率程序在多目标设置下的演绎式策略综合框架，将单目标最弱前置期望理论推广到凸Hoare幂域上的多目标版本，并以混合确定化策略实现Pareto前沿上的权衡。该方法无需有限状态空间限制，为无限MDP上的多目标优化提供了符号化的程序级路径，未来有望进一步扩展至更复杂的不确定性模型和策略类。

Abstract: Probabilistic programs with nondeterminism model planning problems in which a strategy resolves the nondeterminism to optimize an expected outcome. We study the multiobjective setting, optimizing several outcomes at once along a Pareto front, and provide a deductive, program-level account of strategy synthesis. Its core is a multiobjective preexpectation transformer mapping a tuple of postexpectations to the set of simultaneously achievable values, an element of the convex Hoare powerdomain. It conservatively extends weakest preexpectations and lifts standard loop rules. We develop rules to synthesize witnessing strategies as mixed determinizations that randomize over non-probabilistic determinizations. We prove the transformer and synthesis rules sound against an operational MDP semantics, without requiring a finite state space: our approach can be seen as a symbolic approach - at program level - for multiobjective optimization over infinite MDPs. We demonstrate our machinery using various case studies.

</details>
