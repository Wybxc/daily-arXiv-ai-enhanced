### [1] [Decode-Time Grammars: Constrained LLM Generation over a Refinement Order of Grammar Fragments](https://arxiv.org/abs/2607.18357)
*Shuoming Zhang,Ruiyuan Xu,Haofeng Li,Qiuchu Yu,Yangyu Zhang,Chunwei Xia,Xiaobing Feng,Chenxi Wang,Huimin Cui,Jiacheng Zhao*

Main category: cs.PL

TL;DR: 本文提出解码时语法（decode-time grammars）方法，通过从运行时环境Gamma实例化语法片段，在代码生成过程中自动消除对未定义符号的引用，确保生成代码的语义正确性。该方法在TileLang、SQL和P4等多种低资源编程面上，以适中的开销显著消除幽灵引用。


<details>
  <summary>Details</summary>
Motivation: 大语言模型生成的代码在主流语言上表现良好，但在领域特定语言、自定义库API和命令行工具等低资源编程面上仍然脆弱，即使在语法约束解码下仍会产生对未声明变量、缺失列、不存在的API或不受支持的选项等无效引用（幽灵引用）。现有方法缺乏对运行时环境上下文的感知，无法保证引用语义的正确性。

Method: 提出解码时语法框架：从运行时环境Gamma中实例化语法片段，通过区域特定策略为每个孔洞选择合适的片段，并利用收紧算子将开放引用位置替换为Gamma类型化槽位（候选集为当前环境可用的名称、字段、API或选项）。新生成的声明在后续区域解码前进入Gamma，使约束语法依赖已生成的前缀内容。形式化定义了环境索引语法及其精化序，证明了Gamma槽位片段的No-Ghost可靠性，并展示了精化保持该保证集特性的性质。

Result: 在gproj系统中实现该方法，涵盖离线语法归纳和在线策略解析。在TileLang、SQL和P4三种低资源编程面上，使用0.6B至236B参数规模的模型进行实验，结果表明该方法在适中的约束解码开销下，通过构造消除了幽灵引用。

Conclusion: 解码时语法通过将运行时环境信息动态注入语法约束，有效解决了LLM代码生成中的引用错误问题，为低资源编程面的语义正确性提供了可靠保障。该方法在多个领域和模型规模上均验证有效，且开销可控。

Abstract: Large language models now write a growing share of the world's code, increasingly inside agents and serving systems that compile, execute, or dispatch generated code without line-by-line review. This works well for mainstream languages but remains brittle for low-resource programming surfaces such as domain-specific languages, custom library APIs, and command-line tools. Even under grammar-constrained decoding, a model can still produce references invalid in the current environment: a buffer never declared, a column absent from the schema, a function the library does not provide, or an unsupported CLI option.
  This paper introduces decode-time grammars: grammar fragments instantiated during generation from a runtime environment Gamma. A region-specific policy selects a fragment for each hole, and a tightening operator replaces open reference positions with Gamma-typed slots whose candidates are exactly the names, fields, APIs, or options available at that point. Newly generated declarations enter Gamma before later regions are decoded, so the constraining grammar can depend on the prefix already generated. This ensures not only grammatical correctness but also semantic correctness, by preventing references to undefined symbols.
  We formalize grammar fragments as environment-indexed grammars ordered by refinement, prove No-Ghost soundness for Gamma-slotted fragments, show that refinement preserves this support-set guarantee, and characterize the boundary of mask-enforceable properties. We implement the approach in gproj with offline grammar induction and online policy resolution. Across TileLang, SQL, and P4, with models from 0.6B to 236B parameters, gproj eliminates ghost references by construction at moderate overhead over standard constrained decoding.

### [2] [Extended Abstract: From Pattern Unification Towards Pattern Matching Unification](https://arxiv.org/abs/2607.18455)
*David Richter,Timon Böhler*

Main category: cs.PL

TL;DR: 本文指出现有依赖类型语言中基于模式的合一化（如Miller模式）无法合成通过case analysis定义的函数，导致来自类型推断（尤其是归纳原理使用）的约束无法求解。作者提出将依赖模式匹配集成到合一化过程中，通过延迟约束并用模式匹配编译器求解，原型系统能推断出Rocq和Lean等系统拒绝的解，为统一类型推断与模式匹配编译提供了新方向。


<details>
  <summary>Details</summary>
Motivation: 现有依赖类型语言中的高阶合一化（特别是Miller模式及其扩展）存在根本性局限：无法合成通过case analysis（分情况分析）定义的函数，导致类型推断中产生的约束（尤其是来自归纳原理的约束）无法被求解。

Method: 作者提出将依赖模式匹配集成到合一化过程中，实现了一个小型依赖类型语言的原型系统，该系统收集延迟的合一化约束，并通过模式匹配编译器来求解这些约束。

Result: 原型系统成功推断出当前Rocq和Lean等系统拒绝的解，证明了该方法的有效性。

Conclusion: 该工作表明将依赖模式匹配纳入合一化过程是一个有前景的新方向，能够统一类型推断与模式匹配编译，突破了现有系统的能力边界。

Abstract: We revisit the role of higher-order unification in dependently typed languages and identify a fundamental limitation of existing pattern-based fragments: their inability to synthesize functions defined by case analysis. Even simple and ubiquitous constraints arising from type inference, particularly from use of induction principles, fall outside the expressive power of Miller patterns and their modern extensions. We observe that such constraints naturally correspond to definitions by dependent pattern matching. Motivated by this correspondence, we propose integrating dependent pattern matching into the unification process. We present a prototype implementation of a small dependently typed language that collects delayed unification constraints and resolves them via a pattern matching compiler. Our approach successfully infers solutions that are rejected by current systems such as Rocq and Lean, suggesting a new direction for unification that unifies type inference and pattern matching compilation.

### [3] [Formal Verification of an Out-of-Order Multiprocessor against an In-Order Weak-Memory ISA](https://arxiv.org/abs/2607.18727)
*Janggun Lee,Jeehoon Kang*

Main category: cs.PL

TL;DR: 本文首次实现了对乱序多处理器（支持弱内存模型）的无界形式化验证，通过精心设计的核心规范将多余的乱序执行捕获为指令列表，并将证明分解为核心精化与系统包含两个步骤，最终在Rocq中借助LLM代理自动完成了机械化证明。


<details>
  <summary>Details</summary>
Motivation: 乱序多处理器的验证面临两个核心挑战：核间交错（读写访存顺序无限制）与核内乱序执行（指令不按程序顺序发射），二者结合会产生无顺序执行可解释的弱行为。现代ISA虽允许这些行为，但微架构在验证中会进入ISA禁止的临时状态（多余的乱序执行），这使全系统验证中的推理变得复杂。此前工作未能实现对产生此类弱行为的乱序多处理器的无界验证。

Method: 核心思想是设计一个精良的核心规范，将多余的执行捕获为单一指令列表。在此基础上将证明分解为两步：(1) 核心精化——证明核心实现相对于该规范的正确性，抽象掉除多余执行和核心接口外所有微架构状态；(2) 系统包含——将乱序内存执行和核间交错序列化为ISA行为，借助核心规范轻松消除多余执行。所有证明在Rocq中机械化，并利用LLM代理自动编写证明。

Result: 首次实现了对乱序多处理器（针对有序、弱内存ISA）的形式化验证，解决了此前无界验证的空白。

Conclusion: 通过巧妙的核心规范设计与两步分解证明策略，成功实现了对乱序多处理器的无界形式化验证，并借助LLM代理提高了证明自动化的程度。

Abstract: Out-of-order multiprocessor is a critical piece of modern hardware, and their verification must solve the following challenges. First, inter-core interleaving, in which the order their reads and writes reach shared memory is unrestricted. Second, intra-core out-of-order execution, in which instructions fire out of program order. The combination of the two yields weak outcomes, which no sequential execution explains, and modern ISA allows such behaviors to account for them. However, the microarchitecture even exhibits excess out-of-order executions, temporarily entering states forbidden by the ISA. While discarded later, such states complicate reasoning about the core in full-system verification. Prior works verify a range of processor designs, while none have performed unbounded verification for out-of-order multiprocessor exhibiting such weak outcomes.
  We present the first formal verification of an out-of-order multiprocessor against an in-order, weak-memory ISA. Our key idea is a well-designed core specification, which captures the essence of excess executions in a single list of instructions. Building upon this, we decompose the proof into two steps. The first is a core refinement, proving a core implementation against this specification, abstracting away every microarchitectural state except those necessary to reason about excess executions and the core interface. The second is a system inclusion, serializing the out-of-order memory executions and inter-core interleaving into the ISA, easily removing excess executions thanks to the core specification. All of our proofs are mechanized in Rocq, heavily utilizing large language model (LLM) agents to write proofs automatically.

</details>


### [4] [High-Level Synthesis of Efficient Pipelines with Visibility Control](https://arxiv.org/abs/2607.18765)
*Jungin Rhee,Minseong Jang,Jaewoo Kim,Jeehoon Kang*

Main category: cs.PL

TL;DR: 本文提出了一种基于可见性控制（Visibility Control）的新型HLS工具，在顺序编程模型内嵌入细粒度流水线控制，统一了停顿、旁路、推测、延迟提交和寄存器重命名等冒险解决策略，在RISC-V处理器、直方图和AES加速器上实现了优于传统HLS工具且可媲美手写RTL的PPA性能。


<details>
  <summary>Details</summary>
Motivation: 现有HLS工具在流水线并行性上存在两难：要么缺乏对流水线结构和冒险解决的细粒度控制，要么为提供这种控制而牺牲顺序语义。

Method: 提出可见性控制（Visibility Control）这一新型编程抽象，统一多种冒险解决策略；将细粒度流水线控制嵌入顺序编程模型，支持快速设计空间探索。

Result: 在RISC-V核上实现了停顿、旁路、推测和寄存器重命名；在直方图上实现了此前需要RTL或并发编程模型的调度策略。编译后的流水线优于具有顺序语义的HLS工具，PPA与手写RTL相当。

Conclusion: 可见性控制抽象能够在不牺牲顺序语义的前提下提供细粒度流水线控制，实现了兼具高级抽象和底层性能的HLS方案。

Abstract: High-level synthesis (HLS) raises the abstraction of hardware design from concurrent register-transfer level (RTL) programs to sequential programs. Among the forms of parallelism HLS exploits, pipelining demands fine-grained control over pipeline structure and hazard resolution to achieve competitive power, performance, and area (PPA). However, existing tools either lack such control or sacrifice sequential semantics to provide it.
  We present an HLS tool that embeds fine-grained pipeline control in a sequential programming model, enabling rapid design-space exploration. The tool builds on visibility control, a novel programming abstraction that unifies hazard resolution strategies including stalling, bypassing, speculation, deferred commit, and register renaming. We evaluate on in-order RISC-V cores, histograms, and an AES accelerator. On RISC-V cores, we implement stall, bypass, speculation, and register renaming; on histograms, we implement scheduling strategies that previously required RTL or concurrent programming models. Compiled pipelines outperform HLS tools with sequential semantics and achieve PPA comparable to hand-written RTL.

### [5] [VirtualSet: Typed Ontology Worlds as an LLM Generation Target for Grounded Queries and Guarded Decisions](https://arxiv.org/abs/2607.18821)
*Qunhui Zhang*

Main category: cs.PL

TL;DR: VirtualSet是一种替代SQL的接收器类型化本体-世界接口，通过泛型约束投影（GCP）实现执行前语义检查，在BIRD基准上达到67.5%准确率（比SQL+修复+投票高4个百分点），并在守卫决策场景中零误报地拦截了全部20个幻觉动作体。


<details>
  <summary>Details</summary>
Motivation: SQL在LLM使用企业数据时提供延迟的错误信号：幻影字段或关系可能执行并返回看似合理但错误的答案，而错误的写入操作在执行后无法安全评估。需要一种在执行前就能捕获类型错误的机制。

Method: 提出VirtualSet框架：(1) 用实体-边世界上的集合表达式替代SQL；(2) 泛型约束投影（GCP）在执行前检查表达式；(3) 通过集合链保留具体接收器类型，将无效字段、边、接收器和操作转化为锚定在token上的类型错误；(4) 类型正确的读操作使用SQL快速路径或有界流解释，配合奇偶校验预言机；(5) 守卫决策：动作先在模拟世界运行，世界变更事件需外部批准才能具体化。

Result: 在BIRD基准1,072道冻结题目上，VirtualSet达67.5%准确率，比经术语表匹配的SQL+修复+投票的63.5%高4个百分点（McNemar精确检验p=0.00117）。全语料分析未发现引擎对类型正确表达式的计算错误，剩余错误源于模型语义或参考答案缺陷。在30个体的守卫语料库中，写操作链以零误报拦截了20/20个幻觉动作体。

Conclusion: VirtualSet在SQL的主场基准上保持了竞争力，同时为守卫决策提供了执行前语义保证。

Abstract: Large language models increasingly read and act on enterprise data, but SQL gives a late error signal: hallucinated fields or relations can execute and return plausible wrong answers, while incorrect writes cannot be safely assessed after execution. We present VirtualSet, a live, receiver-typed ontology-world interface and generation target for LLMs. Instead of SQL, the model emits set expressions over entity-edge worlds. Generic Constraint Projection (GCP) checks expressions before execution, while future this preserves concrete receiver types through collection chains, turning invalid fields, edges, receivers, and actions into token-anchored type errors. Type-clean reads use a SQL fast path or bounded stream interpretation, with a parity oracle checking both paths over the exercised operator space. The same substrate supports guarded decisions: actions run first in a simulated world, and world-change events require external approval before actualization. On BIRD, we lift relational schemas into typed worlds and compare VirtualSet with direct SQL while holding the model, evidence, values, zero-shot setting, timeout, glossary, repair/voting, and grader constant where possible. On a frozen 1,072-question split, VirtualSet achieves 67.5% accuracy versus 63.5% for glossary-matched direct SQL with repair and voting (+4.0 points; McNemar exact p = 0.00117) using deepseek-reasoner. Full-corpus analysis finds no engine mis-computation of a type-clean expression; remaining errors arise from model semantics or gold defects. In a 30-body guard corpus, the write chain intercepts 20/20 hallucinated action bodies with zero false positives. VirtualSet thus remains competitive on SQL's home benchmark while providing pre-execution semantics for guarded decisions.

### [6] [Build-Authorized Evidence for Opaque Calls: A Fail-Closed Rewrite-Authority Boundary](https://arxiv.org/abs/2607.18949)
*Zhonghua Yi*

Main category: cs.PL

TL;DR: 本文提出了一种构建授权的路径效应接口，通过失败-关闭授权和链接收据来约束编译器重写的权限边界，确保语义事实的改写权限仅限于已接受的事实、选定的提供者、构建环境、调用者、回调环境、观察点和运行时目标。通过Toka原型系统在LLVM上实现检查的生产部署，使用单跳拓扑负载重用作为权威的最小可观察见证。实验表明，授权IR保留不透明调用，减少相关负载，而错误配置和不受支持的IR保持中立。
