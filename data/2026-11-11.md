### [1] [Two-Sided Amortized Resource Analysis: Verifying Resource Lower Bounds via Ill-Typing](https://arxiv.org/abs/2611.12925)
*Zimu Chen,Di Wang*

Main category: cs.PL

TL;DR: 提出一种带有 potential 的双边类型系统，可在同一系统中验证函数式程序的资源下界与上界；通过基于值状态的语义类型证明安全性，并用 OCaml 原型在19个基准上验证精确匹配的成本界定。


<details>
  <summary>Details</summary>
Motivation: 自动均摊资源分析（AARA）只能验证上界，而资源下界是"必要性"陈述（资源足够程序才会求值）。已有的基于类型的方法需通过切换 potential 的亚结构纪律，把上界与下界放在两套独立的类型系统中，无法统一。作者希望用单一证明系统同时刻画上下界。

Method: 将 AARA 式 potential 与 Ramsay-Walpole 的双边类型系统结合（其核心保证是 ill-typed 程序不求值）。类型公式可约束任意项并出现在 turnstile 两侧；判断 t : A ⊢ q 表示"若 t 求值为类型 A 的结果，则至少需 q 单位资源"，即 q 为下界。由于 potential 使类型公式不可复制，系统采用 affine 纪律而非原框架的可复制上下文。通过值状态（值与其剩余资源的二元组）上的语义类型解释类型，并在一个安全片段上证明可靠性。另并行研究了一个双边线性类型系统（所有值均为不可复制资源），其中捕获线性资源的闭包需要双重类型公式。

Result: 在安全片段上证明了系统可靠性；推论在单一证明系统中恢复了经典双边保证以及两类界（上界与下界）的可靠性。OCaml 原型类型检查器在19个基准测试上验证了能精确刻画成本的匹配上下界对，并对上界不可得的程序给出了下界。线性类型系统的探索则解释了主系统 affine 设计的来源。

Conclusion: 双边类型系统 + potential 可在统一框架内同时验证资源上下界；匹配的上下界即刻画程序的精确成本。potential 的不可复制性自然要求 affine 纪律，而线性变体中的双重类型公式进一步说明该设计的必要性。

Abstract: We present a two-sided type system with potential for verifying resource lower bounds of functional programs. Automatic amortized resource analysis (AARA) verifies upper bounds: types carry potential, and typing certifies sufficient resources. A lower bound, however, is a necessity statement---the program evaluates only if enough resources are available---and prior type-based approaches obtain it by switching the substructural discipline of potential, so that upper and lower bounds live in separate type systems. Matching upper and lower bounds characterize a program's cost exactly.
  Our system combines AARA-style potential with the two-sided type systems of Ramsay and Walpole, whose central guarantee is that ill-typed programs do not evaluate. Typing formulas may constrain arbitrary terms and appear on both sides of the turnstile; the judgment $t : A \vdash q$ states that if $t$ evaluates to a result of type $A$, then at least $q$ units of resource must be available---that is, $q$ is a lower bound. Because potential makes typing formulas non-replicable, our system follows an affine discipline instead of the replicable contexts of the original framework. We interpret types by semantic typing over value states, pairs of values and remaining resources, and we prove soundness on a safety fragment; corollaries recover the classical two-sided guarantees and the soundness of both kinds of bounds in a single proof system. A prototype type checker in OCaml verifies, on a suite of 19 benchmarks, matching pairs of bounds that characterize costs exactly, as well as lower bounds for programs whose upper bounds are unavailable. In a parallel exploration, we study a two-sided linear type system in which every value is a non-replicable resource; there, closures that capture linear resources call for dual typing formulas, and the exact accounting explains the affine design of the main system.

Abstract: Modern accelerators specialize recurring computation and replicate it across regular hardware structures to achieve high performance. Sustaining this parallelism requires equally deliberate data delivery. Yet design tools often express these structures as sequential programs or flatten them into separate hardware modules and connections. <details>
  <summary>Details</summary>
Motivation: 传统类型系统只验证安全性（值落在类型指称之内），较新的系统关注可达性（必须能取到类型所指称的全部值）。同时支持二者困难，因为二者对类型上下文中的变量绑定解释提出不同约束。

Method: 将类型上下文视为一种资源，用以调节类型化程序时可用的能力；形式化定义了上下文能力的资源代数，并在其上构建了束式模态上下文逻辑（bunched modal context logic），再将类型系统在该逻辑中解释。

Result: 建立了相对于指称语义的可靠性（soundness），该指称语义在单一类型判断中统一了安全性与可达性保证。

Abstract: Most type systems are designed to verify safety properties: the judgement $e : τ$ holds if $e$ may evaluate to any value contained in the denotation of $τ$, but nothing more. This paper introduces a refinement type system for higher-order functional programs where types can capture both safety and reachability properties. Simultaneously supporting both is challenging because each imposes different constraints on how variable bindings in a typing context are interpreted. We address this challenge by treating typing contexts as a kind of resource that mediates which capabilities are available when typing a program. We formalize this notion by developing a resource algebra of contextual capabilities and a bunched modal context logic over this algebra. We then interpret our type system in this logic, establishing soundness with respect to a denotational semantics that unifies safety and reachability guarantees within a single typing judgement.
