### [1] [Proving LLM-Generated GPU Kernels Correct and Safe: Floating-Point Verification in Lean and VerCors](https://arxiv.org/abs/2610.24548)

Main category: cs.PL

TL;DR: 本文研究语言模型能否从高层基准规格生成正确的GPU内核，并提出一个框架：LLM智能体利用Lean内嵌的命令式程序验证器Velvet证明高层规格与生成CUDA内核的语义等价，同时用并行代码演绎验证器VerCors证明线程安全与无数据竞争。核心贡献在于证明Lean自动化与模型引导的证明构造相结合，可在浮点值上验证一批基础神经网络构件，使LLM能实现语义正确且安全的内核；浮点验证不依赖编译代码，始终由Lean内核检查。

Abstract: Modern statistical model development begins with a high-level specification in an automatic differentiation framework such as PyTorch, JAX, or TensorFlow, which is then lowered to a target backend by a compiler or implemented manually by a research engineer. We introduce a framework in which a language-model agent uses Velvet, a program verifier for imperative programs embedded in Lean, to prove semantic equivalence between a high-level specification and a generated CUDA kernel under an explicit set of assumptions. It also asks the LLM to prove thread safety and data race freedom of the generated kernel in VerCors, a deductive verifier for parallel code. Our main contribution to the formal verification of LLM- generated GPU kernels is showing that a combination of Lean automation and language-model-guided proof construction can verify a broad set of basic neural- network building blocks over floating-point values, allowing LLMs to implement semantically correct and safe kernels. In our framework, floating-point verifications never rely on compiled code and are always checked via the Lean kernel.

### [2] [Structure-Aware Equivalence for Evaluating Autoformalized Statements](https://arxiv.org/abs/2610.25018)
*Yi Yu,Yu-Hsuan Wu,Guang Lin,Yuhui Zhang,Yuxiang Peng*

Main category: cs.PL

TL;DR: 论文提出 Structure-Aware Equivalence (SAE)——一种介于语法等价与整体语句逻辑等价之间、保持角色（role-preserving）的形式等价关系，并在 Autoformalization Correctness Evaluator (ACE) 中实现，输出可认证的等价/不等价判定，否则报告 Inconclusive。在 ProofNetVerif 上 ACE 保持较高等价覆盖率且对争议/不等价对高度保守；诊断中 BEq+ 接受 94–96% 无关但整体逻辑等价的语句对，Mathesis LeanScorer 接受 42% 局部语义扰动，而 ACE 均不接受。


<details>
  <summary>Details</summary>
Motivation: 自动形式化语句评估需判断候选是否保留可信参考的原始数学论断。现有方法分两路：无参考的学习型评估器估计语义一致性但不受形式等价关系约束；基于参考的证明方法用整体语句逻辑等价提供形式证书，粒度过粗，无法刻画翻译保真度，且可能将数学上无关的语句判为等价。因此需要一个既具形式正当性、又保留翻译相关数学结构的等价关系。

Method: 定义 SAE：一种保持角色（role-preserving）的形式等价关系，位于语法等价与整体语句逻辑等价之间，允许形式可证的重述但保留翻译相关的数学结构。将 SAE 操作化为 ACE 评估器，输出三类判定：可认证的等价、可认证的不等价、以及 Inconclusive。并构建 ProofNetVerif 基准（随 BEq+ 一同提出）用于评测。

Result: 在 ProofNetVerif 上，ACE 保持可观的等价样本覆盖率，同时对争议或不等价样本对的认证极为保守。定向诊断中：BEq+ 对无关但整体逻辑等价的语句对接受率达 94–96%；Mathesis LeanScorer 对局部改变语义的扰动接受率为 42%；ACE 对这两类集合均不接受任何样本为等价。

Conclusion: SAE/ACE 在形式严谨性与翻译保真度之间取得折中：以角色保持的等价关系提供可认证判定并显式报告不确定性，避免了粗粒度整体逻辑等价的假阳性与学习型评估器缺乏形式约束的问题，在基准与诊断中表现出高精确性与保守性。

Abstract: Evaluating autoformalized mathematical statements requires determining whether a candidate preserves the mathematical claim intended by a trusted reference. Existing methods approach this problem from complementary directions: reference-free learned evaluators estimate semantic agreement but are not constrained to a formal equivalence relation, while reference-based proof methods typically employ whole-statement logical equivalence to provide formal certificates, which is too coarse for translation fidelity and may identify mathematically unrelated statements.
  We introduce Structure-Aware Equivalence (SAE), a role-preserving formal equivalence relation between syntactic and whole-statement logical equivalence that allows formally justified reformulations while preserving translation-relevant mathematical structure. We operationalize SAE in the Autoformalization Correctness Evaluator (ACE), which provides certified equivalence or inequivalence judgments and reports Inconclusive otherwise. On ProofNetVerif, a benchmark introduced with BEq+, ACE retains substantial equivalent-case coverage while remaining highly conservative in certifying disputed or inequivalent pairs. On targeted diagnostics, BEq+ accepts 94-96% of unrelated but whole-statement logically equivalent pairs, while Mathesis LeanScorer accepts 42% of localized meaning-changing perturbations; ACE accepts none of either set as equivalent.

Method: 核心思路是把每个环境分类器映射到一个上下文。作者构造一个带多态环境分类器、子类型、可变引用的源演算，并将其编译为目标演算——基于CMTT、含多态上下文、可变引用与一等替换的演算；随后在Agda中机械化证明编译保持类型（preservation）与保持元程序行为。

Abstract: Type systems for metaprogramming take one of two approaches to safeguarding the scopes of variables in generated code. The key idea is to map each environment classifier to a context. We prove that the compilation preserves types and that compilation preserves the behavior of metaprograms. Both proofs are mechanized in Agda. The compilation shows that CMTT is at least as expressive as environment classifiers. We conjecture that the converse compilation is difficult, because environment classifiers impose a stricter regime on the metaprogram.
